# Third-party data licenses

perq imports real-world place/business records from **Overture Maps Places**, licensed under
the **Community Data License Agreement – Permissive, Version 2.0 (CDLA-Permissive-2.0)**.

- Full license text: `LICENSES/CDLA-Permissive-2.0.txt`.
- Obligation on redistribution of the raw Data: include the CDLA license text (CDLA §2.1).
- CDLA §3.1 ("No Restrictions on Results"): perq's own derived data (discounts, evidence,
  community reports, eligibility) is unencumbered and may be combined freely with place data.
- In-app attribution: display "Places data © Overture Maps" in credits; the map view also
  carries Mapbox's required attribution.

See `docs/PLACE_DATA_STRATEGY.md` for the full rationale and source comparison.
